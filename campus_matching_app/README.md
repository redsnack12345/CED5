# 교내 실시간 활동 매칭 앱 (Flask + SQLite)

## 실행
```bash
python -m venv venv
# Windows PowerShell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
브라우저에서 http://127.0.0.1:5000 접속.

첫 실행 때 `campus.db`가 생성되며 화면 확인용 수업 데이터가 들어갑니다.

## PDF 화면 흐름 반영
- 월~금 / 1A~7B 시간표 표시
- 수업 시간은 파란색, 공강은 흰색, 참여한 활동은 초록색
- 공강 클릭 → 방 생성 / 방 찾기
- 방 찾기 → 선택 날짜·시간과 겹치는 모집 중인 방 목록
- 방 선택 → 제목·날짜·시간·설명·참여 인원과 참여 버튼
- 방 생성 → 선택한 공강 날짜·교시가 기본 입력값으로 설정
- 참여 완료 → 해당 활동이 시간표에 표시

## DB 구조
- `users`: 사용자
- `timetable`: 사용자별 요일·교시·과목·강의실
- `rooms`: 매칭방 제목, 설명, 날짜, 시간, 장소, 정원, 상태
- `room_members`: 방 참여자

## 실제 DB 연동 전 수정할 점
- `USER_ID = 1`을 로그인 세션의 사용자 ID로 교체
- `timetable` 조회 SQL을 팀의 실제 시간표 테이블에 맞게 수정
- `SLOTS`의 교시별 시작/종료 시각을 학교 실제 시간표에 맞게 수정
- PDF에는 교시별 실제 시각이 없어 현재 시간값은 데모용입니다.
- 현재는 데모 사용자 한 명으로 동작하며 로그인·학교 인증은 미구현입니다.
- 배포 전 인증/권한검사, CSRF 방어, 동시 참여 시 정원 초과 방지 트랜잭션, 중복 일정 검사 등을 보강해야 합니다.
