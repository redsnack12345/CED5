CampusMatching 사용자 인증 V1.0 (터미널 프로토타입)

실행 방법 (Windows / VS Code)
1. ZIP 파일 압축 해제 후 해당 폴더를 VS Code에서 연다.
2. 터미널에서 python -m pip install -r requirements.txt 실행
3. python test_auth.py 실행
   python 명령이 인식되지 않으면 py 명령을 시도한다.
4. 메뉴에서 회원가입한 뒤 같은 프로그램 실행 중에 로그인한다.
   비밀번호 입력 문자가 화면에 표시되지 않는 것은 정상이다.

파일 구성
- data.py: 공통 메모리 저장소
- auth.py: 회원가입, 로그인, 비밀번호 해시, 제재 상태 확인
- verification.py: 학교 검색, PDF 문자열 추출 및 정보 검사
- test_auth.py: 터미널 시연 메뉴
- requirements.txt: PDF 처리 외부 라이브러리

제한 사항
- HTML, Streamlit, 실제 DB, 계정 복구, 최종 학교 인증 승인 미구현.
- 모든 계정 및 증명서 데이터는 프로그램 종료 시 사라진다.
- 증명서 문자열 일치 검사는 진위 확인이 아니다. 이미지 PDF OCR 미지원.
- 인증 완료 전에는 매칭 이용이 제한된다.
- 실제 개인 정보 대신 가상 정보로 테스트할 것.
- 함수명, 공통 저장 구조, 최소 비밀번호 길이 8자, PDF 최대 5 MiB는 임시 설계.
- 인증 함수는 로그인된 사용자 ID를 호출부가 안전하게 전달한다는 가정에 기반한 로컬 시연용이다. 실제 웹서비스에는 별도 세션 및 권한 검증이 필요하다.
